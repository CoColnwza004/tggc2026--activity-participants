# สะสมตรา ลุ้นรางวัล · TGGC 2569

เว็บกิจกรรมบูธ **การแข่งขันอัจฉริยภาพทางด้านภูมิศาสตร์และภูมิสารสนเทศแห่งประเทศไทย ระดับมัธยมศึกษา ครั้งที่ 3**
เสาร์ 28 พ.ย. 2569 · โรงเรียนชลประทานวิทยา จ.นนทบุรี

มี 2 เว็บแยกกัน ใช้ฐานข้อมูลเดียวกัน (Cloudflare D1):

| เว็บ | ใช้ทำอะไร |
|---|---|
| **ผู้เข้าร่วม** `participant/` | เปิดสมุดสะสมตรา → สแกน QR ที่บูธรับตราน้องจีออส → ครบทุกบูธไปสแกน QR จุดลุ้นรางวัล → ลุ้น (ได้/ไม่ได้) · สูจิบัตร: กำหนดการ ผังงาน บูธ แนะนำน้องจีออส |
| **เจ้าหน้าที่** `staff/` | ใส่ PIN → เลือกบูธ → จอแสดง QR + รหัส 6 หลักที่**เปลี่ยนทุก 30 วินาที** · สแกนสมุดผู้เข้าร่วม (กรณีมือถือเขาสแกนไม่ได้) · จุดลุ้นรางวัล: รายชื่อผู้โชคดี + กด "มอบแล้ว" · แอดมิน: ภาพรวม แก้จำนวนของรางวัล/โอกาสได้รางวัล ดาวน์โหลด CSV ล้างข้อมูลทดสอบ |

## กันโกง
- QR ที่บูธเปลี่ยนทุก 30 วินาที (คล้าย OTP) ถ่ายรูปส่งต่อเพื่อนก็ใช้ไม่ได้ (รับย้อนหลังได้ไม่เกิน ~10 นาที เผื่อเน็ตหลุดตอนสแกน)
- สุ่มรางวัลที่เซิร์ฟเวอร์ 1 สมุดลุ้นได้ 1 ครั้ง (กดซ้ำ/สองเครื่องพร้อมกันก็ได้ผลเดียว) ตัดสต็อกอัตโนมัติ ของหมด = ไม่ได้รางวัล
- ต้องสแกน QR ที่จุดลุ้นรางวัลเท่านั้นจึงลุ้นได้ · ใส่รหัสผิดเกิน 15 ครั้ง/10 นาที ล็อกชั่วคราว · PIN ผิดเกิน 12 ครั้ง/15 นาที ล็อก

## รองรับคนเยอะ
- ไฟล์หน้าเว็บทั้งหมดเสิร์ฟจาก CDN ของ Cloudflare โดยตรง (ไม่นับโควตา Worker) มีเฉพาะ `/api/*` ที่วิ่งเข้า Worker
- ไฟล์ทุกไฟล์มี hash ในชื่อ → cache 1 ปี · CSS ฝังในหน้า · ตัวสแกน/สร้าง QR โหลดเฉพาะตอนกดใช้
- **ใช้ได้แม้เน็ตในงานล่ม**: เปิดเว็บครั้งแรกแล้ว เปิดซ้ำได้ทันที (service worker) · สแกนตอนไม่มีสัญญาณ ตราจะขึ้นก่อนแล้วส่งเข้าระบบให้เองเมื่อกลับมาออนไลน์ · จอ QR ของเจ้าหน้าที่สร้างรหัสได้แม้ออฟไลน์
- ประมาณการ 3,000 คน × 6 บูธ ≈ 25,000 คำขอ API — อยู่ในโควตาฟรีของ Workers (100,000/วัน) และ D1 สบาย ๆ

## แก้ข้อมูลงาน
ทุกอย่างอยู่ใน **`shared/event.js`** ไฟล์เดียว: รายชื่อบูธ (ชื่อ, ที่ตั้ง, สี, ไอคอน, ตำแหน่งบนผัง), จุดลุ้นรางวัล, ของรางวัลเริ่มต้น, โอกาสได้รางวัล, กำหนดการ, ผังงาน
> ⚠️ บูธ กำหนดการ และผังงานตอนนี้เป็น**ข้อมูลตัวอย่าง** แก้ให้ตรงงานจริงก่อน · ถ้ามีรูปผังจริง วางไฟล์ใน `assets/` แล้วตั้ง `map.image`
> หลังเปิดให้สะสมตราแล้ว **อย่าเปลี่ยน `id` ของบูธ**

## Deploy (Cloudflare Workers + D1)
ครั้งแรก:
```bash
npm install
npx wrangler login
npx wrangler d1 create tggc2569-activity
```
คัดลอก `database_id` ที่ได้ ไปใส่ทั้ง `participant/wrangler.jsonc` และ `staff/wrangler.jsonc` แล้ว
```bash
npm run deploy
npx wrangler secret put STAFF_PIN -c staff/wrangler.jsonc
npx wrangler secret put ADMIN_PIN -c staff/wrangler.jsonc
```
- ตารางในฐานข้อมูลสร้างเองอัตโนมัติเมื่อมีการใช้งานครั้งแรก
- ได้ URL เช่น `https://tggc2569-activity.<ชื่อบัญชี>.workers.dev` และ `https://tggc2569-activity-staff.<ชื่อบัญชี>.workers.dev`
- **นำ URL เว็บผู้เข้าร่วมไปใส่ `participantUrl` ใน `shared/event.js` แล้ว `npm run deploy` อีกครั้ง** (QR ที่บูธจะชี้ไปที่ URL นี้ — สแกนด้วยกล้องมือถือปกติก็เปิดเว็บและรับตราได้เลย)

แก้ไขครั้งต่อไป: `npm run deploy`

## ก่อนวันงาน (checklist)
1. แก้ `shared/event.js` → deploy
2. เข้าเว็บเจ้าหน้าที่ด้วย ADMIN_PIN → แอดมิน → ตั้งจำนวนของรางวัล และโอกาสได้รางวัล
   - แนะนำใส่ **จำนวนผู้ลุ้นที่คาดไว้** ระบบจะปรับโอกาสอัตโนมัติให้ของพอแจกจนจบงาน
3. ทดลองครบ flow ด้วยมือถือ 2 เครื่อง (เครื่องหนึ่งเปิดจอบูธ อีกเครื่องสแกน)
4. แอดมิน → **ล้างข้อมูลทดสอบ** (พิมพ์ RESET) ก่อนเปิดงานจริง
5. ทำป้าย QR ลิงก์เว็บผู้เข้าร่วม ติดทางเข้า/โต๊ะลงทะเบียน (ให้คนเปิดเว็บครั้งแรกตอนเน็ตยังดี)
6. เจ้าหน้าที่ทุกบูธล็อกอินไว้ก่อนเปิดงาน · กด "เต็มจอ" · ตั้งไม่ให้จอดับ (ระบบขอ wake lock ให้แล้ว)

## ลองใช้แบบไม่ต่อเซิร์ฟเวอร์
เปิดเว็บผู้เข้าร่วมพร้อม `?demo=1` (เช่น `http://localhost:8787/?demo=1`) ข้อมูลอยู่ในเครื่อง ใส่รหัส 6 หลักอะไรก็ได้

## พัฒนาในเครื่อง
```bash
printf 'STAFF_PIN=111111\nADMIN_PIN=999999\n' > staff/.dev.vars
npm run build
npx wrangler dev -c participant/wrangler.jsonc --persist-to .wrangler/state --port 8787
npx wrangler dev -c staff/wrangler.jsonc --persist-to .wrangler/state --port 8788 --inspector-port 9230
```

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `shared/event.js` | ข้อมูลงาน (บูธ กำหนดการ ผัง ของรางวัล) |
| `shared/otp.js` | รหัสหมุนเวียน 30 วินาที (HMAC-SHA256) ใช้ทั้งเบราว์เซอร์และเซิร์ฟเวอร์ |
| `shared/server.js` | ฐานข้อมูล, ตรวจรหัส, สุ่มรางวัล (ใช้ร่วมกันทั้ง 2 Worker) |
| `participant/worker.js`, `staff/worker.js` | API ของแต่ละเว็บ |
| `participant/src/` | หน้าเว็บผู้เข้าร่วม (ลูกโลกจุด 3D `globe.js`, ตราประทับ `stamps.js`, service worker) |
| `staff/src/` | หน้าเว็บเจ้าหน้าที่ |
| `shared/web/` | ไอคอน, สร้าง QR, สแกนกล้อง, เอฟเฟกต์ (คอนเฟตตี เสียง สั่น) |
| `assets/` | รูปที่ใช้จริง (สร้างจาก `assets-src/` ด้วย `scripts/make-assets.py`, `scripts/make-og.mjs`) |
| `scripts/build.mjs` | build → `dist/participant`, `dist/staff` |
| `vendor/` | qrcode-generator (MIT, Kazuhiko Arase), jsQR (Apache-2.0) |
